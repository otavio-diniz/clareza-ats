# Contribuições e feedback

O **Clareza ATS** é uma aplicação acadêmica de portfólio publicada para demonstração e revisão técnica. Contribuições de qualidade e relatos reproduzíveis são bem-vindos. O repositório **não possui licença open source para reutilização irrestrita**; consulte [LICENSE](LICENSE) e [NOTICE.md](NOTICE.md).

## Como relatar um problema

Abra uma [issue](https://github.com/otavio-diniz/clareza-ats/issues) com contexto suficiente para reproduzir:

1. Descrição do comportamento observado e do resultado esperado.
2. Passos mínimos usando **vaga e currículo inteiramente fictícios**; quando possível, comece pelo botão *Carregar exemplo fictício*.
3. Navegador, sistema operacional e, para reprodução local, versões de Node.js e npm.
4. Capturas ou mensagens de erro sanitizadas, sem nomes reais, dados pessoais, endereços, chaves, tokens ou caminhos locais privados.

### Temas úteis

Acurácia de correspondências e falsos positivos; conservação das informações curriculares; acessibilidade e responsividade; exportação/diagramação PDF; reprodução, documentação e dependências.

## Alterações propostas

Descreva primeiro o problema e a proposta em uma issue antes de mudanças substanciais. Pull requests não são automaticamente autorizados ou aceitos e não constituem licença, cessão ou transferência implícita de direitos. Mudanças eventualmente aceitas dependem de proveniência, compatibilidade e termos pertinentes.

Mantenha escopo objetivo, testes reproduzíveis e nenhuma alegação de certificação ATS ou resultado real de recrutamento. O [guia de reprodução](docs/guia-reproducao.md) é a referência para executar e validar o projeto.

**Privacidade:** não anexe currículos verdadeiros, anúncios confidenciais, credenciais, logs com identificadores pessoais ou dados de processos seletivos.
